## Minecraft
Running Minecraft servers is what I'm most passionate about. I love the world of Minecraft, but what I love more are the stories that people can tell with it. If not for Minecraft, I would not be pursuing a career in computer science. I've learned how to use docker, code in Java, python, JavaScript, etc. Here are some of the things I've developed for my private Minecraft servers that I'm most proud of.

### Vanilla Mob Heads:
<img width="1280" height="720" alt="thumbnail3" src="https://github.com/user-attachments/assets/61dd9af9-9abf-4caa-9d11-86baf031f457" />

[Video Showcase](https://www.youtube.com/watch?v=1CfagoLt-zg&t=5s) | [MCPEDL](https://mcpedl.com/vanilla-mob-heads/) | [GitHub](https://github.com/RWRmrfrog/VMH)

Vanilla Mob Heads is my attempt at creating the most vanilla friendly mob head addon for Minecraft. As of writing this, the addon has over 27k downloads, and I (somewhat) consistently update it. Not only did a lot of work go into the scripting side of things, but also the modeling and overall vision of the addon. I also created a nice little python script to help automate the creation of all (170-ish?) heads, which you can find on the GitHub page.
